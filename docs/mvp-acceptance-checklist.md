# MVP §7 测试与验收清单

对应 [mvp.md](./mvp.md) §7。自动化部分由 `pnpm run test:mvp` 执行；**UI 与安装包体验**须按下表人工勾选。

---

## 0. 运行自动化（推荐先做）

```bash
# 完整：build + 静态检查 + Electron 原生冒烟
pnpm run test:mvp

# 仅静态（无 Electron）
pnpm run test:mvp -- --static-only
```

报告输出：

- `test-results/mvp-acceptance-report.md`
- `test-results/mvp-acceptance-report.json`

### 可选环境变量

| 变量 | 用途 |
|------|------|
| `CHM_ASSISTANT_GBK_SAMPLE` | GBK 编码样例 `.chm` 路径（7.1） |
| `CHM_ASSISTANT_GBK_SEARCH_QUERY` | 全文搜索关键字，默认 `的` |
| `CHM_ASSISTANT_GBK_PAGE_QUERY` | 页内中文检索关键字（RD-08b 粗测） |
| `CHM_ASSISTANT_CORRUPT_SAMPLE` | 损坏样例；默认 `test/fixtures/corrupt/invalid.chm` |
| `CHM_ASSISTANT_LARGE_SAMPLE` | 超大 CHM（7.4） |

样例文件说明见 [test/fixtures/README.md](../test/fixtures/README.md)。
